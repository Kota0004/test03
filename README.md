# ノート

思ったことを貯めて、整理して、アイデアに変えていく場所。

## 使い方

**チャットに思ったことを貼るだけ。** それ以外に覚えることはない。

貼ると Claude が:

1. 原文そのままを `notes/2026-09.md` に時系列で記録する（改変しない）
2. 短い読み取りとタグをつける
3. 過去のメモとの繋がりを探して返す
4. 溜まってきたら `themes/` にまとめ、発想が出たら `ideas/` に立てる
5. コミットして push する

長さも形式も気にしなくていい。一行でも、箇条書きでも、愚痴でも、
推敲してない思考の断片でもそのまま貼ってほしい。整えるのはこちらの仕事。

### 言いたいことがあるとき

貼るだけでなく、こう言えば動く:

| 言うこと | 起きること |
|---|---|
| 「最近何書いてたっけ」 | 直近のログを振り返って返す |
| 「〇〇についてまとめて」 | そのタグ・テーマのノートを読んで整理し直す |
| 「何かアイデアない?」 | テーマの交差点を探して具体案を出す |
| 「これ前にも書いてた?」 | 過去ログを検索して該当箇所を返す |
| 「このテーマもう古い」 | themes を更新、または ideas を「却下」に移して理由を残す |

## 構成

```
CLAUDE.md          Claude 向けの運用ルール（これが記憶の仕組みの本体）
INDEX.md           全体の地図。テーマ、アイデア、今の関心、未解決の問い
notes/YYYY-MM.md   生ログ。原文のまま、時系列、追記のみ、編集しない
themes/*.md        テーマごとの清書。何度でも書き換えて育てる
ideas/*.md         具体的な発想。却下したものも理由を添えて残す
scripts/note.sh    振り返り・検索・タグ一覧の小道具
```

生ログは **追記のみ・編集しない**。考えが変わったら新しく書いて古いほうを指す。
古い自分と新しい自分の両方が残るようにしてある。

## コマンド（任意）

チャットだけで完結するが、手元で見たいとき用:

```bash
./scripts/note.sh recent        # 直近20件を表示
./scripts/note.sh recent 50     # 件数を指定
./scripts/note.sh find 設計     # 全ノートを全文検索
./scripts/note.sh tags          # タグを使用回数順に一覧
./scripts/note.sh tag 設計      # そのタグのついたエントリを表示
./scripts/note.sh add "思ったこと"  # チャットを使わず直接追記
./scripts/note.sh stats         # ノート数・テーマ数などの概況
```

`add` で直接足したぶんは読み取りもタグもつかない。
次にチャットを開いたとき Claude が拾って整理する。
