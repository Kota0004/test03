# 生き方 — 自分は何をして生きるか

タグ: #生き方 / 状態: 育成中 / 最終更新: 2026-09-25

## いまの理解

本人が楽しいと感じるのは、**使われたときの嬉しさ、ものづくりそのもの、頭の中のものが形になっていく
過程、そこで出てくる課題を解くこと**の4つ（n-2026-09-24-08）。本人によれば、この4つは切り離せない
1つのループで、全部を垂直統合でやりたい（n-2026-09-24-09）。どれも、障壁を消していく
「過程」の中にある。

住みたい世界は、障壁のない世界（n-2026-09-24-08）。大切にしたいのは経済的自由で、その意味は
「決定するときに、経済的要因で選択肢が狭まらないこと」（n-2026-09-24-06）。

## わかってきたこと

- 事業を立ち上げ、金銭的束縛から解放され、その事業で人類を搾取から解放したい（n-2026-09-23-01）
- 学生の今は、経済的自由が真っ先に来る問題（n-2026-09-24-05）
- 障壁がすべてなくなったら、死んでもいいかも（n-2026-09-24-07）
- 自分が住みたい世界は、障壁のない世界（n-2026-09-24-08）
- 楽しいのは、使われたときの嬉しさ、ものづくり、形になっていく過程、課題の解決（n-2026-09-24-08）
- 4つは1つに絞れない。課題を解く過程で形を考え、解けたかは使ってみないとわからず、フィードバック
  まで含めて課題解決だから。4つ全部を垂直統合でやるのが答え（n-2026-09-24-09）
- 1人が全てを握るのは、その1人が善であれば、今の世界ではむしろいいことかもしれない。その後は思想の
  似た有力者たちで世界がまとまるかもしれない。自分がその1人になりたい気もする（n-2026-09-24-09）

### 参照している人物

- **トニー・スターク**（架空、n-2026-09-23-01）— 「とても似ている気がする」
- **イーロン・マスク**（実在、n-2026-09-24-08）— 同じような世界を夢見ている人
- 映画のスタークはマスクを参考の一人にしており、『アイアンマン2』にはマスク本人が出演している。
  2人は同じ系譜

### Claude の整理

- **4つの楽しさには、お金も地位も悪人退治も入っていない。** そして全部、経済的自由を得る前の今、
  RoomRadar で味わえている（n-2026-09-24-08）
- **スタークに似ているのは、億万長者の部分ではなく工房の部分かもしれない。** 洞窟でマーク1を
  組み立てる場面と、本人の4つはそのまま重なる（n-2026-09-24-08）
- **「使われる嬉しさ」があることが、作り手を現場につなぎとめる。** 作る側が住む人の感覚から
  ずれるおそれ（n-2026-09-24-07）を防ぐのは、使う人の顔を見続けること
- **4つは1つのループ。** 課題 → 形にする → 使われる → フィードバック → 課題。リーンスタートアップの
  「作る・測る・学ぶ」と同じ形に、本人が自分でたどり着いている。向く仕事は、分業された一部分ではなく、
  ループ全体を自分（か少人数）で回せる場所（n-2026-09-24-09）
- **段階1（稼ぐ事業）を選ぶ基準になる。** 4つが残る仕事かどうか。稼げても4つが消える仕事は、
  「段階1で別人になる」（ideas/自由の設計.md）につながりやすい（推測）
- **マスクから輸入していい部分と、してはいけない部分がある。** 重なるのは宇宙・病気の治療・
  技術で障壁を消すこと。違うのは中心で、マスクは人類という種の存続、本人は一人ひとりの選択
  （ダラダラしたい人はそれでいい）。Claude が n-2026-09-24-05 で出した原理「誰であっても1人で全部を
  動かせないようにする」と、巨大なインフラが1人の判断で左右されるマスクのあり方には緊張がある。
  ただし本人はこの原理に同意しておらず、逆の見方を持っている（n-2026-09-24-09、下記）

### 権力について（本人と Claude で見方が分かれている）

- 本人: 善である1人が全てを握るのは、今の世界ではむしろいいことかもしれない。自分がその1人に
  なりたい気もする（n-2026-09-24-09）
- 本人: ただし、その1人が自分ではなく会ったこともない誰かなら、望まない（n-2026-09-25-01）
- Claude の反論（n-2026-09-24-09）:
  - **本人のループと衝突する。** フィードバックが届くのは、使う人が「使わない」を選べるから。
    1人が全てを握ると、誰も離れられず、正直なフィードバックが届かなくなる
  - 善かどうかは外から確かめられない。本人が置いた「本質的に害を与えたい人はいる」
    （n-2026-09-24-04）と同じ理由で、仕組みを1人の善さに賭けることはできない
  - 善人でも代替わりする。ローマ五賢帝の最後、マルクス・アウレリウスの後継は息子のコンモドゥス
  - 善い主人に仕える奴隷も自由ではない（ペティットの「非支配としての自由」。相手が実際に干渉しなく
    ても、いつでも干渉できる状態なら自由ではない）
  - 思想の似た有力者で世界がまとまる、は本人の理想（一人ひとりが違うことを選べる）と逆向き
  - 「その1人になりたい」は、トニー・スタークの最大の失敗（ウルトロン、n-2026-09-23-01）と同じ形
- 同じ「垂直統合」の本能が2か所に出ている（Claude の整理）。ものづくりの垂直統合はループを速く
  回すための正しい選択。権力の垂直統合はループを壊す
- Claude の読み（n-2026-09-25-01、本人に確認中）:
  - 1人支配の魅力は「誰がその1人か」に左右されていた。自分なら望み、他人なら望まない。
    ほとんどの人が同じ答えになり、権力分立はこの答えから出てくる（ロールズの「無知のヴェール」:
    自分がどの立場になるか知らないとしたら、どんなルールを選ぶか）
  - 欲しかったのは「1人が全てを握る世界」ではなく、「自分のやりたいことを誰にも止められない状態」
    ではないか。本人の経済的自由の定義（決定のとき選択肢が狭まらない）と同じ形（推測）
  - 野心の形の言い直し: **「全てを握る1人」ではなく、「いつでも離れられるのに選ばれ続ける1人」。**
    後者は本人のループ（フィードバック）とも、理想（一人ひとりが選べる）とも両立する。
    RoomRadar の約100人は、すでに後者の形で使っている
